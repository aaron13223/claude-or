Changelog
=========

All notable changes to claude-or are recorded here.
Format: based on Keep a Changelog (https://keepachangelog.com/en/1.1.0/).
Versioning: Semantic Versioning 2.0.0 (https://semver.org/).
Newest release first. Dates are YYYY-MM-DD.

[Unreleased]
------------
Added
- `deepseek-api` alias and `deepseek:<model>` IDs run DeepSeek's models on
  DeepSeek's own Anthropic-compatible API with DEEPSEEK_API_KEY, instead of
  OpenRouter. Permission prompts are skipped by default there; `--auto` uses a
  DeepSeek classifier. The status line shows the DeepSeek balance and session
  tokens, split into fresh input, cached input and output.

Changed
- The `deepseek` alias now runs at reasoning effort `high` instead of `max`,
  which spent most of the output cap thinking and made turns take much longer.
  Set `effort=max` in your aliases file to restore the old behaviour.
- Document Chrome DevTools MCP as the browser automation path for custom models,
  and clarify why native Claude in Chrome needs a direct subscription session.

[1.5.0] - 2026-11-21
--------------------
Added
- CLAUDE_OR_DEFAULT_MODEL: Enter at the model menu picks it, and a flag as the
  first argument (`./claude-or -p "hi"`, `./claude-or --no-auto`) runs it.
- Your own aliases in ~/.config/claude-or/aliases (or CLAUDE_OR_ALIASES_FILE),
  with optional context=, maxout= and effort=, so updates never conflict.
- `--doctor`: checks the OpenRouter key, Codex login, Claude Code version,
  status line and skills sync without launching.
- `--check-aliases`: compares every alias's model, provider pin, context window
  and output cap with OpenRouter and the Codex model cache.
- Test suite for the ChatGPT proxy and launch logic
  (`python3 -m unittest discover -s tests`).

Changed
- Faster launch: Claude Code's version is cached until it updates, and
  OpenRouter endpoint lookups for a day (a stale copy is used when offline).
- Per-session usage totals older than 30 days are deleted.

Fixed
- claude-or exited silently with status 1 on machines without synced account
  skills (no ~/.claude/skills/synced), or with skills but no synced plugins.
- Pressing Enter at the model menu crashed with "bad array subscript"; it now
  asks again (or picks the default).
- A flag as the first argument failed with "Unknown alias".
- An invalid CLAUDE_CODE_EXTRA_BODY silently dropped the provider pin and
  reasoning effort; the launch now stops with an error.
- Provider pins and effort values containing quotes produced invalid JSON.
- Launching failed under bash older than 4.4 when no plugins were loaded.


[1.4.0] - 2026-11-21
--------------------
Added
- Status line shows what the current session has used: exact dollar cost on
  OpenRouter, tokens and plan-limit points on ChatGPT. Includes side requests
  (classifier, titles, subagents) and persists per session.

Changed
- With the status line on, OpenRouter requests go through a local pass-through
  (forwarded unchanged) so each response's cost can be counted.


[1.3.0] - 2026-11-21
--------------------
Added
- Usage status line: OpenRouter credits left (and key limit), or ChatGPT plan
  5h/weekly limits with reset times, always visible and cached across runs.
  Off with CLAUDE_OR_STATUSLINE=0; skipped if you set your own statusLine.

Fixed
- No more "claude.ai connectors are disabled" warning on every launch
  (connectors can't load under OpenRouter/ChatGPT auth anyway).


[1.2.0] - 2026-11-21
--------------------
Added
- ChatGPT subscription backend: `chatgpt` and `chatgpt-mini` aliases and any
  `chatgpt:<slug>` model run on your ChatGPT plan through the Codex login,
  via a built-in local proxy. No OpenRouter key needed for these.
- Auto mode in ChatGPT mode uses gpt-6-luna as its safety classifier, on the
  same subscription.
- CLAUDE_OR_PROXY_LOG to log ChatGPT proxy requests and errors.

Changed
- OPENROUTER_API_KEY is only required for OpenRouter models.


[1.1.0] - 2026-11-21
--------------------
Added
- `--version` / `-V` flag; CLAUDE_OR_VERSION constant in claude-or.
- changelog.txt, CLAUDE.md, README.md, .env.example.

Changed
- .gitignore now ignores .env and the generated .skills-plugin/.


[1.0.0] - 2026-11-21
--------------------
Added
- First release: claude-or launches Claude Code against OpenRouter.
- Model aliases (gpt, gpt-mini, grok, gemini, gemini-flash, deepseek, qwen,
  kimi, glm, claude) and interactive picker; any OpenRouter model ID accepted.
- `alias@provider` pins (provider.only, no fallbacks).
- Per-alias reasoning effort, context window, and output token cap, with live
  lookup from OpenRouter for unknown models or command-line pins.
- Auto permission mode via local classifier (anthropic/claude-haiku-5.5);
  `--no-auto` to bypass prompts.
- Appended system prompt from system-prompt.md (overridable by env vars).
- Account skill re-exposure via generated .skills-plugin/.
- Prompt suggestions forced on; telemetry and nonessential traffic disabled.
- Warning when installed Claude Code is newer than TESTED_CC_VERSION.
